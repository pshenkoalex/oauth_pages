# OAuth Park

Интерактивная модель OAuth 2.0 / OpenID Connect на русском языке.

## Маршруты

Четыре маршрута проекта по предоставленным UML: вход через auth ID, SSO, step-up и ре-аутентификация. Дополнительно сохранены классические примеры OIDC Code + PKCE, OAuth-доступа к API документов, refresh и client credentials.

Участники проекта: браузер, gateway, authorization (OIDC Client/RP), auth ID (OP/AS), сервис экосистемы. Сервис объявлен в UML без сообщений; его протокол защиты не предполагается. UserInfo не указан в исходных UML. Указанный introspection отделён от UserInfo и проверки ID Token.

Изменения относительно UML помечены в интерфейсе как предложения, а не как согласованные решения. Полный shared-разговор был недоступен; использованы сами исходные схемы.

Пауза, шаги, скорость, шкала времени, сценарии отказа, справочник и чек-лист. Симуляция не делает настоящих OAuth-запросов; значения примерные. Длительности сессий и контракт бизнес-API задаются реализацией.

## Публикация

GitHub Pages: main / (root). Сборка не требуется. Для локального просмотра: `python3 -m http.server 8000`, затем `http://localhost:8000`.
